# Steam Hunter

Steam Hunter находит временно бесплатные игры Steam со скидкой 100%.

Во вкладке «Скидки» можно просматривать действующие акции, загружать следующие страницы и искать игру по названию. Карточка показывает процент скидки и открывает официальную страницу Steam.

В репозитории находятся две версии:

- веб-приложение в папке `app`;
- самостоятельное Android-приложение в папке `android`.

## Как получить APK

Откройте раздел **Releases** на GitHub и скачайте файл `Steam-Hunter.apk` последней версии.
Android предупредит, что приложение установлено не из Google Play — это нормально для учебной версии из собственного репозитория.

Приложение не спрашивает логин или пароль Steam. Кнопка «Забрать в Steam» открывает официальную страницу игры, где пользователь сам подтверждает получение.
